# 德州扑克胜率与行动复盘工具

一个**单文件 HTML 应用** —— 无构建、零依赖、双击即用。打开 `texas-holdem-equity-calculator.html` 就能跑，不需要装任何东西。

---

## 功能

### 1. 胜率计算
- 输入自己的手牌、公共牌、对手手牌（对手可设**已知**或**未知**）
- 支持 **2~9 人**同桌，多人池按座位分别给出份额
- 翻牌前 / 翻牌 / 转牌 / 河牌 各阶段胜率
- 精确枚举优先（预算 600 万次），超出自动降级为蒙特卡洛
- all-in 胜率与跟注 EV 计算

### 2. 可视化牌桌模拟
- 椭圆 9 人桌，**等弧长布点**，星标标出自己的座位
- 每个座位可单独设手牌，支持**一键切换「未知」**（切回自动还原）
- 中央实时显示底池，底部显示前注构成
- 实时份额表：每个座位当前的胜率占比

### 3. 行动复盘
- **逐手行动线**：记录每一街、每个位置的动作
  - 动作类型：`过牌` / `跟注` / `下注` / `加注` / `全下` / `弃牌`
  - 每录一手，底池**立刻**重新计算
- **逐街判定**：对比「实际动作」与「该做的动作」，给出 0~10 分和一句可读解释
- **综合评分**：`总分 = 平均分 × 55% + 最低分 × 45%`，最弱环节定上限，最后映射为 S~F 评级

### 4. 全部按金额记账
- 大盲、前注、各街投入**统一用金额**（元 / 筹码），不用「多少个大盲」换算
- 起始底池 = `大盲 × 2 + 每人前注 × 人数`（盲注位补满到大盲，无独立小盲）
- 默认值：大盲 **6 元**、前注 **6 元**、手牌与公共牌**默认未知**

## 判定逻辑简述

核心是一个对比：**你这手牌的胜率** vs **一个「够不够格」的门槛**。

| 阶段 | 胜率来源 | 门槛构成 |
|---|---|---|
| 翻牌前 | 对随机牌胜率 + 可玩性加分（同花 / 真连牌 +2%） | 位置基准 + 加注尺寸调整 + 人数调整 − 前注放宽 |
| 翻牌后 | 精确枚举 / 蒙特卡洛真实胜率 | 底池赔率换算的盈亏平衡点 `下注额 / (底池 + 2 × 下注额)` |

位置基准（越早越严）：`UTG 58% → MP 54% → CO 50% → BTN 48% → BB 43%`

### 诚实边界

判定**只看胜率 / 赔率这一个维度**，不含对手范围建模、位置对抗、隐含赔率、诈唬频率、下注尺度的心理博弈。
所以「建议动作」是**参考线，不是绝对正解**。

## 快速上手

1. 双击打开 `texas-holdem-equity-calculator.html`（推荐 Chrome / Edge）
2. **胜率计算** tab：填手牌和公共牌，看胜率
3. **行动复盘** tab：
   - 先摆桌（人数、自己的位置、大盲、前注）
   - 给每个座位选手牌，不知道的留「未知」
   - 逐街记录每个人的动作和金额，底池会实时更新
   - 点「分析这手牌」，看每街判定和总分

> 页面上有示例按钮，可以一键载入几局典型牌型参考。
